NASA Space Apps Challenge | Python, Skyfield, FastAPI, Three.js, Cloudflare | November 2026

- Built a 3D mission-planning app comparing nine Artemis candidate regions, landing dates, power needs, and Earth-contact windows; deployed the frontend on Cloudflare Pages, Python API on Containers, and terrain data on R2.

- Integrated JPL ephemerides and NASA LOLA terrain data, reducing mean sunlight deviation from NASA reference maps from 19.7% to 2.0% across nine regions over a 19-year validation period.

- Ranked 90 landing targets using terrain slope, walkable solar-panel placement, and battery sizing.

- Integrated Cloudflare Workers AI with 10 tools for site comparisons, power sizing, and document retrieval, grounding numerical answers in deterministic calculations and precomputed mission data.
